A tiny Python program (standard library only, no network) that writes a single deadpan one-star review of gravity to `/output/entry.txt`. Gravity is only ever flawless when it hurts you: drop your phone face-down and it works perfectly. A real grievance, filed in earnest against a thing that cannot be fixed, with the sting arriving in the last few words.

> One star. Gravity works fine until you drop your phone face-down, then it works perfectly.

The entry is one line, 90 characters, within the 160-character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
